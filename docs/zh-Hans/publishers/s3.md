# 对象存储

[English](../../en/publishers/s3.md) | 简体中文

`s3`、`minio`、`oss` 和 `cos` target 共用同一套 S3 Signature V4 上传实现。`qiniu` target 则使用七牛云原生上传接口。

## S3 兼容参数

以下参数适用于 `s3`、`minio`、`oss` 和 `cos`：

| 参数               | 说明                                                             |
| ------------------ | ---------------------------------------------------------------- |
| `endpoint`         | API endpoint；未写协议时自动补 `https://`                         |
| `region`           | 区域                                                             |
| `access-key`       | Access key                                                       |
| `secret-key`       | Secret key                                                       |
| `bucket`           | Bucket 名称                                                      |
| `key-prefix`       | 可选对象键前缀，用 `/` 与文件名连接（别名 `savekey-prefix`）      |
| `public-base-url`  | 可选公开下载地址前缀（别名 `bucket-domain`）                      |
| `force-path-style` | 是否使用 path-style URL（`true`/`false`、`1`/`0`、`yes`/`no`、`on`/`off`） |

发布结果为 `<public-base-url>/<key>`；未设置 `public-base-url` 时为上传地址。

## S3 / MinIO

```bash
export S3_ENDPOINT=https://s3.example.com
export S3_ACCESS_KEY=access-key
export S3_SECRET_KEY=secret-key
export S3_BUCKET=downloads
```

```bash
fastforge publish --path dist/app.zip --target s3 \
  --publish-arg key-prefix=releases/1.0.0
```

| 参数               | 环境变量                                                   | 默认值     |
| ------------------ | ---------------------------------------------------------- | ---------- |
| `endpoint`         | `S3_ENDPOINT`、`MINIO_ENDPOINT`                            | 必填       |
| `region`           | `S3_REGION`、`AWS_REGION`                                  | `us-east-1` |
| `access-key`       | `S3_ACCESS_KEY`、`AWS_ACCESS_KEY_ID`、`MINIO_ACCESS_KEY`    | 必填       |
| `secret-key`       | `S3_SECRET_KEY`、`AWS_SECRET_ACCESS_KEY`、`MINIO_SECRET_KEY` | 必填     |
| `bucket`           | `S3_BUCKET`                                                | 必填       |
| `key-prefix`       | `S3_KEY_PREFIX`                                            | 无         |
| `public-base-url`  | `S3_PUBLIC_BASE_URL`                                       | 上传地址   |
| `force-path-style` | `S3_FORCE_PATH_STYLE`                                      | `true`     |
| `session-token`    | `AWS_SESSION_TOKEN`                                        | 无         |

`minio` target 执行相同的上传，但会优先读取 `MINIO_ENDPOINT`、`MINIO_ACCESS_KEY` 和 `MINIO_SECRET_KEY`，再读取 `S3_*` 变量。不存在 `MINIO_BUCKET` 或 `MINIO_REGION` 变量；请使用 `--minio-bucket`、`--minio-region`、`--minio-savekey-prefix`，或 `S3_*` 变量。

## 七牛云

```bash
export QINIU_ACCESS_KEY=access-key
export QINIU_SECRET_KEY=secret-key
export QINIU_BUCKET=downloads
export QINIU_PUBLIC_BASE_URL=https://download.example.com

fastforge publish --path dist/app.zip --target qiniu \
  --publish-arg savekey-prefix=releases/1.0.0/
```

七牛云使用上传凭证进行表单上传，上传域名会根据 bucket 自动探测，没有 region、endpoint 或 path-style 配置。

| 参数                                | 环境变量                | 说明                                             |
| ----------------------------------- | ----------------------- | ------------------------------------------------ |
| `access-key`                        | `QINIU_ACCESS_KEY`      | 必填                                             |
| `secret-key`                        | `QINIU_SECRET_KEY`      | 必填                                             |
| `bucket`                            | `QINIU_BUCKET`          | 必填（`--qiniu-bucket`）                         |
| `bucket-domain`、`public-base-url`  | `QINIU_PUBLIC_BASE_URL` | 下载域名（`--qiniu-bucket-domain`）              |
| `savekey-prefix`、`key-prefix`      | —                       | 原样拼接在文件名前；需要目录时请带上末尾的 `/`   |

发布结果为 `<bucket-domain>/<key>`；未提供下载域名时，结果为字面量 `<bucketDomain>/<key>`。

## 阿里云 OSS

```bash
export OSS_ACCESS_KEY=access-key
export OSS_SECRET_KEY=secret-key
export OSS_BUCKET=downloads
export OSS_REGION=cn-hangzhou

fastforge publish --path dist/app.zip --target oss
```

region 为必填。endpoint 只能通过 `endpoint` 参数设置，默认生成 `oss-<region>.aliyuncs.com`。可选变量：`OSS_KEY_PREFIX`、`OSS_PUBLIC_BASE_URL`、`OSS_FORCE_PATH_STYLE`（默认 `false`）。

## 腾讯云 COS

```bash
export COS_ACCESS_KEY=access-key
export COS_SECRET_KEY=secret-key
export COS_BUCKET=downloads-1250000000
export COS_REGION=ap-guangzhou

fastforge publish --path dist/app.zip --target cos
```

region 为必填。endpoint 只能通过 `endpoint` 参数设置，默认生成 `cos.<region>.myqcloud.com`。可选变量：`COS_KEY_PREFIX`、`COS_PUBLIC_BASE_URL`、`COS_FORCE_PATH_STYLE`（默认 `false`）。

Access key 与 secret key 也可以作为参数传入，但建议通过环境变量提供，避免留在命令历史中。
